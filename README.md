# The Editorial Developer

A personal portfolio website designed around an editorial, magazine-inspired visual language.

The portfolio combines AI engineering, full-stack development, typography, asymmetrical layouts, burgundy and cream tones, and a recurring illustrated character to create a distinctive personal identity.

## Overview

This website presents my work, skills, experience, certifications, and ways to connect through a visual style inspired by premium editorial and fashion magazines.

Rather than following the typical developer portfolio aesthetic of dark backgrounds, glowing cards, and blue/purple gradients, the design uses:

- Deep burgundy and black backgrounds
- Cream editorial typography
- Large display headlines
- Asymmetrical layouts
- Magazine-style composition
- Editorial spacing and hierarchy
- Character-based visual identity
- QR-code presentation
- Subtle motion and interaction
- Minimal borders and decorative elements

The goal is to make the portfolio feel more like a designed publication than a conventional developer website.

---

## Technology

This website is built using only:

- HTML5
- CSS3
- Vanilla JavaScript

No frontend frameworks or UI component libraries are used.

The source code is intentionally kept simple and understandable so that it can be easily edited and maintained while learning HTML, CSS, and JavaScript.

### Not Used

- React
- Next.js
- Vue
- Angular
- Tailwind CSS
- Bootstrap
- External UI component libraries

## Page Structure

The portfolio is organized into the following sections:

### 01 — HERO

The opening section introduces the portfolio with large editorial typography, the illustrated character, and the overall visual identity.

### 02 — WHO AM I?

An introduction section describing who I am, my interests, and my approach to technology and development.

### 03 — WHAT I WORK WITH

A visual presentation of the technologies, tools, and skills I work with.

### 04 — SELECTED WORK

A collection of selected projects showcasing my development and AI work.

### 05 — MY JOURNEY

A timeline-style section presenting important experiences, learning milestones, and development stages.

### 06 — ACHIEVEMENTS / CERTIFICATIONS

A collection of certifications, achievements, and hackathon experiences presented using an editorial collage layout.

### 07 — LET'S CONNECT

A contact section containing my email, location, social links, QR codes, and illustrated character.

### 08 — FINAL CTA

A final call-to-action encouraging visitors to connect and collaborate.

### 09 — FOOTER

The closing section of the portfolio.

## Visual Design

The visual identity is built around a limited color palette.

### Color Palette

| Color | Hex |
|---|---|
| Background | `#180304` |
| Dark Burgundy | `#3A080B` |
| Primary Burgundy | `#78151C` |
| Cream | `#F4E8CC` |
| Text | `#F7F3ED` |
| Muted | `#A99591` |

Burgundy, black, and cream are used as the dominant visual language throughout the website.

The design intentionally avoids the common bright blue and purple gradients often seen in generic developer portfolios.

---

## Typography

Typography plays a major role in the visual identity of the website.

The design uses:

- Large editorial headlines
- Serif display typography
- Small uppercase labels
- Wide letter spacing
- Strong typographic hierarchy
- Oversized section titles
- Asymmetrical text placement

Large typography is used as a visual element rather than simply as content.

---

## Character

A transparent illustrated character is used as a recurring visual identity throughout the website.

The character appears in different sections of the portfolio, including:

- Hero
- About
- Skills
- Contact

The same character is reused rather than generating different illustrations for each section.

Subtle movement and interaction can be applied through CSS and JavaScript, including:

- Gentle floating
- Mouse parallax
- Subtle rotation
- Scroll-based movement

The animations are intentionally restrained to maintain a professional editorial feel.

---

## Interactions

The website includes lightweight interactions created with Vanilla JavaScript and CSS.

Examples include:

- Scroll reveal animations
- Hover effects
- Magnetic-style interactions
- Character movement
- Image hover effects
- Smooth visual transitions
- Interactive CTA elements

No animation framework is required.
